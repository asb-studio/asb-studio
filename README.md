# استودیوی اسب

ویرایشگر مارک‌دان نشر اسب. مارک‌دان منبع حقیقت است؛ HTML هیچ‌وقت ذخیره نمی‌شود.

**برای استفاده، [راهنما](GUIDE.md) را بخوان.** این فایل برای توسعه است.
**برای بردنش آنلاین، [DEPLOY.md](DEPLOY.md).**

## ساختار پوشه

```
asb-studio/
├── index.html          ← استودیو. بیرونِ همه‌ی پوشه‌ها
├── vercel.json         ← هدرهای میزبانی
├── supabase/
│   └── 01-schema.sql   ← جدول مشترک
├── serve.py
├── README.md
├── GUIDE.md
├── webfonts/
│   └── Arad-VF.woff2   ← فونت خانگی
├── logos/
│   └── asblogo.svg     ← نشان نشر
├── vendor/             ← کتابخانه‌های باندل‌شده، بدون CDN
└── src/
```

در کل پروژه فقط **یک** فایل به اسم `index.html` هست و جایش ریشه‌ی پروژه است.

## اجرا

```
python serve.py
```

- استودیو: `http://localhost:8765/`

باز کردن با دابل‌کلیک کار نمی‌کند؛ مرورگر ماژول‌های جاوااسکریپت را روی `file://` بلاک می‌کند.

### قرارداد اصلی

```
serialize(parse(text)) === text
```

فایل باز شود و بدون تغییر ذخیره شود، باید **بایت‌به‌بایت** همان قبلی باشد. «مرور آرشیو» این را روی تک‌تک فایل‌ها می‌سنجد و هر فایلی که از آن رد نشود را **ناسالم** علامت می‌زند.

دلیلش: `build.py` فیلدهایی می‌خواند که فرم نمی‌شناسد (`summary`، `price`، `roles`، `socials`). اگر استودیو کل بلوک را از روی قالب خودش بازنویسی کند، بی‌صدا پاکشان می‌کند.

## موتور مارک‌دان سایت

`build.py` از **Python-Markdown** استفاده می‌کند، نه CommonMark و نه Pandoc:

```python
extensions = ['extra', 'tables', 'attr_list', 'footnotes', 'pymdownx.blocks.html']
footnotes SEPARATOR = '-'
```

قواعدی که با تست واقعی تأیید شده‌اند:

- ویژگی **پاراگراف** فقط روی خط بعدی و تنها → `{: .poem #p-x }`
- ویژگی **عنوان** فقط روی همان خط → `# فصل یک {#chapter-1}`
- شکست خط با `\` کار نمی‌کند. کلاس `.poem` خودش خط‌ها را حفظ می‌کند
- `[متن]{.کلاس}` پشتیبانی نمی‌شود. شکل درست: `**متن**{: .کلاس }`
- `~~خط‌خورده~~` بدون `pymdownx.tilde` رندر نمی‌شود
- شناسه‌ی پانویس‌ها `fn-1` و `fnref-1`

## دسته‌بندی‌ها

دیگر رونویسی دستی نیست. `build.py` با `export_schema.py` فایل `data/categories.json` را می‌سازد و استودیو همان را می‌خواند. فهرست داخل `model/schema.js` فقط پشتیبان است، برای وقتی که آن فایل نباشد.

## امنیت

کلید `anon` در `storage/config.js` **عمومی است و امن**. به‌تنهایی هیچ‌چیز نمی‌خواند و نمی‌نویسد، چون RLS هر درخواستِ وارد‌نشده را رد می‌کند.

کلید `service_role` **هیچ‌وقت** در این پروژه نمی‌آید. جایش فقط `.env` روی لپ‌تاپ است، همان‌جا که `build.py` استفاده‌اش می‌کند.

## کلیدهایی که عمداً استفاده نشدند

`Ctrl+W` و `Ctrl+Tab` مال مرورگرند و کروم `preventDefault` را رویشان نادیده می‌گیرد. بستن سند روی `Alt+W` است و جابه‌جایی روی `Alt+←/→`.
